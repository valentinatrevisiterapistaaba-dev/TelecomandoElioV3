# Telecomando Elio V2

Nuovo progetto Android da zero.

Funzioni:
- BLOCCA = enableLockedMode + attesa 1.5s + startScreensaver
- SBLOCCA = stopScreensaver + attesa 0.8s + disableLockedMode
- AutoMode
- Reset timer
- Test connessione
- IP / password / minuti modificabili
- 3 tentativi automatici per ogni comando
- rete Android standard, senza forzare una specifica Network Wi-Fi
